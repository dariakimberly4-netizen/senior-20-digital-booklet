# 20% Senior Digital Booklet

Mobile-first Senior Citizen 20% discount booklet with separate Senior and Seller experiences.

## Branding
Bacoor-inspired palette: deep blue, royal blue, warm gold, ivory and cream, with green used only for success/eligible states.

## Senior portal
- Large-text controls: A / A+ / A++
- High contrast mode
- Read aloud
- Digital Senior ID
- Find 20% discounts by category
- Clear Regular Price → 20% Discount → Senior Price display
- 20% discount calculator
- Saved items
- Purchase history
- Help screen

## Seller portal
- Add products/services
- Activate/deactivate listings
- 20% eligibility controls
- Record Senior sales
- Verify the local Senior profile
- Reports
- Store profile

## GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save.

The site URL will be:
https://dariakimberly4-netizen.github.io/senior-20-digital-booklet/

## Data note
This static GitHub Pages version stores data in the browser using localStorage. Seller changes sync immediately to the Senior portal in the same browser and across tabs. For real cross-device syncing, user accounts and shared data, connect the frontend to a cloud backend such as Supabase or Firebase.
